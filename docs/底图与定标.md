# 底图与两点定标（L0）

给 `index.html` 加的能力：**把一张户型图照片/截图垫在平面图下面，用两点定标把它换算成真实毫米**，然后照着描、照着量。

> 这是"图像识别"的第一级（L0）。它**不做**自动识墙、自动识门窗 —— 那些是 L1/L2，卡点见本节末。

---

## 1. 怎么用

1. 顶栏 → **底图 ▾** → 「导入图片…」选一张 PNG/JPG。
2. 图片会按画布大小自动缩放居中，并立刻进入定标模式（十字光标）。
3. 在图里点出**一段你已知实际长度**的线的两端（也可以按住拖一条线）：
   - 优先选图上标注了尺寸的墙段，例如一段标着 `2760` 的墙；
   - 没有标注就选一个你能确认的尺寸，比如门洞 900、床宽 1800。
4. 弹出输入框后填真实毫米数，回车或点「确定」。
5. 底图就变成真实比例了。此时：
   - 状态栏的 `X / Y` 读数就是真实毫米；
   - 测量工具量出来的就是真实尺寸；
   - 「底图 ▾」里会显示 `mm/px` 与整张图的 `宽 × 高 mm` —— 这就是你户型的外包络，填 [layout JSON](layout-spec.md) 时直接用。

| 操作 | 说明 |
|---|---|
| 透明度滑块 | 5%–90%，方便描图时看清底下 |
| 两点定标 | 可重复执行；每次都以当前底图为基准重算 |
| 复制定标参数 | 复制 `{mmPerPx, sizeMM, sourcePx}` JSON，供转换器使用 |
| 移除底图 | 清除图片与定标 |

按 `Esc` 可随时取消正在进行的定标。

---

## 2. 定标数学

设两点在平面坐标里的距离为 `L`（mm），你输入的真实长度为 `R`（mm）：

```
k = R / L                     缩放系数
底图宽 ×= k，高 ×= k            （以第一个点击点为不动点）
mmPerPx = 底图宽 / 原图像素宽    （原图 1 像素对应多少 mm）
```

因为 `L` 是从当前 `view.s` 反算的，**缩放画布后重新定标结果一致** —— 这一点在测试里用「填入真实距离 → 尺寸不变（k=1 往返）」验证。

## 3. 实现位置

| 内容 | 位置 |
|---|---|
| SVG 底图图层 `<g id="gUnder" pointer-events="none">` | [index.html](../index.html) svg 内，`<defs>` 之后（最底层） |
| 顶栏菜单 + 定标弹层 | header / main 内 |
| 逻辑（约 120 行） | `/* ===== 底图（导入户型图 + 两点定标） ===== */` 一节 |
| 事件接线 | 在 `pointerdown` / `pointermove` / `onPointerEnd` / `keydown` 开头各加一行 `if (calib) …` 守卫 |

**不侵入原有逻辑**：底图在独立图层，`pointer-events:none` 不影响命中测试；定标期间所有指针事件被守卫提前接管；`renderAll` 不触碰该图层。

三层，全部可重复执行：

| 层级 | 手段 | 结果 |
|---|---|---|
| 语法 | 抽出两段 `<script>` 跑 `node --check` | 0 error |
| 接线 | 检查 10 个钩子、81 个 `#id` 引用是否都存在 | 全 ok |
| 逻辑 | 把这一整段真实代码切出来，套最小 DOM 桩执行 19 条断言 | 19/19 passed |

逻辑断言覆盖：导入后长宽比保持 / 按 BOUNDS 适配 / 居中 / 预填值等于屏幕距离换算的真实 mm / **k=1 往返尺寸不变** / 填 2 倍 → 尺寸翻倍 / `mmPerPx` 同步 / 缩放以起点为不动点 / 取消可恢复 / 0、负数、NaN 不破坏状态 / 信息栏格式。

## 5. 已知边界

1. **图片不持久化**。刷新后需重新导入（图片 Base64 塞进 `localStorage` 有 5MB 配额风险，不做）。定标参数可用「复制」存档。
2. **只能描、不能自动出墙**。当前没有画墙工具，`WALLS` 仍是常量；描好的户型要落成数据，走 [layout JSON](layout-spec.md) → 替换常量这条路。
3. **导出 PNG 不含底图**（底图是参照物，不是方案内容）。
4. **iPad 兼容**：`<image>` 同时写了 `href` 与 `xlink:href`；`createImageBitmap` 不可用时回退到 `<img>` 解码。

## 6. 下一级（L1）要解决什么

要做"半自动识墙"，还差这三件事，且都能用同一套验证：

1. **尺度**：已由本功能解决（两点定标给出 `mmPerPx`）。这是 L1 能成立的前提。
2. **矢量化**：二值化 → 直线检测 → 正交化 → 网格吸附 → 候选墙矩形。
3. **拓扑合法**：候选墙必须满足 [validate-layout.mjs](../tools/validate-layout.mjs) 的"房间边完整覆盖"检查，否则 3D 会漏光。

验收指标：墙段召回 > 85%、房间 IoU > 0.90、转换出的 JSON **首次通过校验率 > 50%**。
